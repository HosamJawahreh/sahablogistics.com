# SAHAB LOGISTICS — Brand & UI Guide

## Approved logo (client-final)
Use the exact supplied artwork in `source-assets/brand/`:
- `sahab-logo-light.png` — use on light/pale backgrounds.
- `sahab-logo-dark.png` — use on dark navy backgrounds.
- `sahab-icon-light.png`, `sahab-icon-dark.png` — favicon/compact use only.

The approved logo is a horizontal cloud-and-truck mark with a flowing white S monogram inside the trailer, followed by the SAHAB wordmark and LOGISTICS descriptor. Do not redraw, retype, crop, recolor, distort, regenerate, or change the truck/S mark.

The supplied logo files are raster images, not original vector masters. Do not create an SVG by simply wrapping a PNG. Request original AI/SVG/PDF artwork from the client for large-format print if needed.

## Visual language
- Premium, modern, calm corporate transportation brand.
- Main body is light ice-blue / white with deep navy headings.
- Use blue/cyan selectively for primary CTAs, icons, underline accents and process indicators.
- Use a deep-blue footer and selective navy sections, not a fully dark page.
- Soft transitions between sections, curved/diagonal image masks only where they match the approved screenshot.
- Generous spacing, aligned content containers, restrained shadows, thin borders and consistent radii.
- Avoid generic logistics template cards, heavy glass panels, overdone glow, random gradients, or a fully light/white blank aesthetic.
- Typography: use Manrope or a close geometric sans-serif; fallback to system sans-serif. The custom logo lettering must never be recreated with a font.

## Logo use
- Header and light panels: `sahab-logo-light.png`.
- Dark footer / dark panels: `sahab-logo-dark.png`.
- Use object-fit: contain, preserve intrinsic aspect ratio.
- Do not add a vertical divider between icon and wordmark; this is part of the approved logo.
